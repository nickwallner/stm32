# STM32

This repository is a collection of my work with stm32. All code is written 100%
from scratch using datasheets and reference manuals.

Right now, I've been working on making drivers for some of the peripherals
on stm32f446xx. My future plans include using those drivers to implement interfaces
for a few different sensors (temp, humidity, ultrasonic, etc).

All my code has been tested using a ST Nucleo-F446RE dev board and the
arm-none-eabi toolchain.
